# FixIt AI - Quick Start Guide

## Setup (5 minutes)

### 1. Install Python Dependencies

```bash
# Navigate to project directory
cd fixit_ai

# Create virtual environment (recommended)
python -m venv venv

# Activate virtual environment
# On Windows:
venv\Scripts\activate
# On Linux/Mac:
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

### 2. Run the Application

```bash
streamlit run app.py
```

The app will open in your browser at `http://localhost:8501`

## Quick Demo Steps

### Step 1: Generate a Battery Report

```powershell
# Run in PowerShell or Command Prompt
powercfg /batteryreport
```

This creates `battery-report.html` in your current directory.

### Step 2: Analyze Battery Health

1. Click "🔋 Battery Check" in the dashboard
2. Upload the `battery-report.html` file
3. View detailed analysis and recommendations

### Step 3: Analyze Event Logs

1. Open Windows Event Viewer
2. Select System or Application log
3. Right-click > Save All Events As... > Save as .txt
4. Click "📋 Event Logs" in FixIt AI
5. Upload the exported log file

### Step 4: Review Diagnostic History

The default dashboard view shows all past diagnostic reports with severity indicators and timestamps.

## Troubleshooting

### Issue: "Module not found"
```bash
pip install -r requirements.txt --upgrade
```

### Issue: Battery report parsing fails
- Ensure the file is generated by Windows `powercfg /batteryreport`
- Check that beautifulsoup4 is installed: `pip install beautifulsoup4 lxml`
